# 🧠 База Знаний и Скилов Агентов (Agent Skills Registry)

В этой директории аккумулируются **основные навыки (Skills)**, полученные ИИ-агентами в процессе реального выполнения задач и решения инженерных проблем.

> **Основной закон:** *Каждый выполненный этап работы и каждый рабочий лог агента трансформируется в формализованный СКИЛЛ, готовый для немедленного использования другими агентами на любых машинах.*

---

## 🛠 Создание нового скилла

При завершении задачи агент выполняет:
```bash
python3 agent_sync.py save-skill \
  --name "new_skill_slug" \
  --title "Понятный заголовок навыка" \
  --desc "Для чего и когда применять этот навык" \
  --log "Путь к логу или текстовое описание процесса"
```
