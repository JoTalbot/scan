# Agent Skill Extraction Protocol

## Purpose
Каждый ИИ-агент после завершения задачи обязан превращать полученный опыт в reusable skill.

## После каждой задачи агент сохраняет:

1. Context
- проблема;
- окружение;
- ограничения.

2. Solution
- что было сделано;
- какие файлы изменены;
- какие команды использованы.

3. Verification
- тесты;
- проверки;
- результаты.

4. Reuse Pattern
- когда применять этот skill;
- ограничения;
- известные ошибки.

## Формат skill

```
skills/<category>/<skill_name>.md
```

## Правила мультиагентов

- Перед началом работы агент читает существующие skills.
- Не создавать дубликаты skills.
- Улучшать существующие skills при повторном опыте.
- Каждое изменение фиксировать в agent log.

## Цикл обучения

Task -> Execute -> Verify -> Extract Skill -> Commit -> Share
