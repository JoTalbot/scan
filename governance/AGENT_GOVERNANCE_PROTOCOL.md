# Agent Governance Protocol

## Purpose

Defines control rules for autonomous agents.

## Principles

- Every critical action is auditable.
- High-risk changes require approval gates.
- Agent decisions must leave traceable records.
- Policies are versioned and reviewable.

## Flow

```
Agent Action
    ↓
Policy Check
    ↓
Approval Gate
    ↓
Execution
    ↓
Audit Log
    ↓
Learning System
```
