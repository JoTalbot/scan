# Agent Audit Analyzer

## Purpose

Analyze agent audit logs and generate governance recommendations.

## Flow

```
Audit Log
   ↓
Analyzer
   ↓
Anomaly Detection
   ↓
Recommendations
   ↓
Governance Update
```

Capabilities:
- detect repeated failures;
- identify agents needing review;
- provide improvement recommendations;
- feed results into evolution cycle.
