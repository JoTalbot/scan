# Memory Architecture 2.0

## Layers

- Agent Memory: temporary context, decisions, execution notes.
- Project Memory: architecture decisions, discoveries, recurring issues.
- Skill Memory: reusable solutions extracted from completed tasks.

## Lifecycle

Observe -> Retrieve Memory -> Execute -> Verify -> Store Learning

## Rules

1. Read relevant memory before starting a task.
2. Store validated knowledge only.
3. Link discoveries to skills.
4. Avoid duplicate knowledge entries.
