# 🎯 Приоритизация CVE (Топ-5)

**Сформирован:** 2026-08-25
**Источники:** `internetdb_report.md` (Shodan InternetDB, 307/327 IP обогащены), `CVE_REPORT.md` (локальная проверка `cve_check.py`).

> **Примечание:** `CVE_REPORT.md` (проверка по баннерам/версиям с самих устройств) не выявил уязвимостей, однако InternetDB сопоставляет CVE по детектированным версиям сервисов. Расхождение означает, что версии ПО видны сканеру, но локальный чекер их не подтвердил — данные InternetDB следует считать оценкой «возможно уязвим» и верифицировать на самом устройстве.

## Методика ранжирования

Приоритет = CVSS 3.x базовый балл × возможность удалённой эксплуатации без аутентификации × наличие публичных эксплойтов/эксплуатации в дикой природе × число затронутых IP в скане.

---

## 1. CVE-2023-38408 — OpenSSH ssh-agent forwarding RCE — CVSS 9.8 (Critical)

Удалённое выполнение кода через перенаправленный ssh-agent (PKCS#11): при подключении по SSH к вредоносному хосту с включённым agent forwarding атакующий исполняет код на машине администратора. Не требует аутентификации со стороны жертвы при определённых условиях, публичные PoC доступны.

**Затронутые IP:**

| IP | Вендор | Открытые порты |
|---|---|---|
| 128.1.33.16 | MikroTik | 22, 53, 80, 554, 5985 |
| 199.189.241.32 | SonicWALL | 22, 443 |
| 213.136.53.171 | OPNsense | 22, 53, 80, 443 |

**Рекомендации владельцу:**
- Обновить OpenSSH до версии ≥ 9.3p2 (на OPNsense — обновить релиз ОС; на MikroTik/SonicWALL — прошивку).
- Не использовать `ssh -A` / `ForwardAgent yes` при подключении к недоверенным хостам; глобально отключить agent forwarding в `~/.ssh/config`.
- Ограничить доступ к порту 22 списком доверенных IP (ACL/файрвол).

## 2. CVE-2022-45315 — MikroTik RouterOS SNMP OOB read → RCE — CVSS 9.8 (Critical)

Чтение за границами буфера в процессе `snmp` RouterOS < 7.6; по данным NVD/Tenable позволяет выполнить произвольный код специально сформированным пакетом. Публичные эксплойты доступны. Наибольшее покрытие в скане — 12 устройств MikroTik.

| 85.187.232.16 | 21, 22, 53, 80, 161 |
| 92.245.157.128 | 80, 2000, 8291, 8728 |

**Рекомендации владельцу:**
- Обновить RouterOS до ≥ 7.6 (желательно до актуального stable/long-term).
- Если SNMP (порт 161) не используется — отключить (`/ip snmp set enabled=no`); если используется — SNMPv3 + ACL по адресам.
- Закрыть с WAN также порты 8291 (Winbox), 8728 (API), 2000 (bandwidth-test), 21/23 (FTP/Telnet) — они видны снаружи у большинства этих устройств.

## 3. CVE-2023-30799 — MikroTik RouterOS эскалация привилегий (FOISted) — CVSS 9.1 (Critical)

Эскалация из `admin` в `super-admin` через интерфейс Winbox/HTTP; в сочетании с подбором пароля даёт полный контроль над устройством (снятие ограничений RouterOS, загрузка произвольного кода). Эксплуатировалась в дикой природе (ботнеты FreakOut/Vo1d), по оценкам сотни тысяч устройств уязвимы.

**Затронутые IP:**

| IP | Открытые порты |
|---|---|
| 82.160.138.224 | 22, 23, 80, 4440, 4443 |
| 85.187.232.16 | 21, 22, 53, 80, 161 |
| 213.5.196.16 | 21, 80, 2000, 8291, 8728 |

**Рекомендации владельцу:**
- Обновить RouterOS до ≥ 6.49.8 / 7.x stable (исправлено в июльских релизах 2023).
- Немедленно сменить пароль администратора (предполагать компрометацию, т.к. CVE активно эксплуатировалась), проверить устройство на посторонние учётные записи, скрипты и scheduler-задачи.
- Закрыть Winbox (8291) и Web (80) от внешнего мира: управление только из VPN/доверенной сети. У 82.160.138.224 открыт Telnet (23) — отключить полностью.

## 4. CVE-2024-6387 — OpenSSH «regreSSHion» — CVSS 8.1 (High)

Гонка сигналов в `sshd` на glibc-системах: неаутентифицированное удалённое выполнение кода от root. Сложная, но массово отрабатываемая атака; публичные PoC опубликованы в день раскрытия.

**Затронутые IP:**

| IP | Вендор | Открытые порты |
|---|---|---|
| 213.136.53.171 | OPNsense | 22, 53, 80, 443 |

**Рекомендации владельцу:**
- Обновить OpenSSH (на OPNsense — до релиза с OpenSSH ≥ 9.8).
- Как временная мера: `LoginGraceTime 0` в sshd_config (снимает вектор, но делает sshd уязвимым к DoS исчерпанием соединений) — применять только до обновления.
- Ограничить доступ к 22/tcp доверенными сетями; включить fail2ban/блокировку по rate-limit.

## 5. CVE-2023-32154 — MikroTik RouterOS RADVD pre-auth RCE — CVSS 7.5 (High)

Запись за границами буфера в Router Advertisement Daemon (radvd) при обработке ICMPv6 Router Advertisement (поле RDNSS). Неаутентифицированное выполнение кода сетевым соседом двумя crafted RA-пакетами; найдена на Pwn2Own Toronto 2022 (DEVCORE), затронуты версии < 6.49.7.

**Затронутые IP:**

| IP | Открытые порты |
|---|---|
| 82.160.138.224 | 22, 23, 80, 4440, 4443 |
| 85.187.232.16 | 21, 22, 53, 80, 161 |
| 95.46.32.176 | 21, 80, 2000, 8291, 8728 |
| 108.60.101.64 | 22, 80, 2000, 8008, 8015 |

**Рекомендации владельцу:**
- Обновить RouterOS до ≥ 6.49.7 / 7.x.
- Если IPv6 не используется — отключить пакет/интерфейсы IPv6 и RA (`/ipv6 nd`, `/ipv6 settings`) — это устраняет поверхность атаки целиком.
- На границах фильтровать неожиданные ICMPv6 RA от WAN (RA должны приходить только от апстрим-маршрутизатора).
