# Отчёт о проекте

В данном репозитории находится комплексный проект вокруг базы данных CIDR-диапазонов интернет-провайдеров: ядро — реляционная база SQLite `isp_cidr.db` (≈508,879 CIDR-блоков, 40,650 автономных систем и ~1.9 млрд IPv4-адресов по Украине, США и 49 странам Европы, собранная из официальных дампов RIPE NCC/ARIN скриптом `build_db.py`), вокруг которой построены инструменты на чистом Python 3.10+ — CLI-утилита `isp_tool.py` для поиска по IP/ASN и экспорта firewall-правил (MikroTik, ipset, iptables, nginx geo, Cisco wildcard), веб-дашборд `web_server.py` с REST API и аналитикой, а также группа сканеров/аудиторов (`port_scanner.py`, `router_detect.py`, `router_auth_check.py`, `bgp_looking_glass.py` и др.) для проверки роутеров на открытые порты, слабую аутентификацию и уязвимости. Вторая особенность репозитория — инфраструктура распределённой параллельной разработки силами ИИ-агентов: протокол координации через `AGENTS.md`, живая доска статусов `STATUS.md` + `agent_state.json`, утилиты синхронизации `agent_sync.py`/`sync_manager.py`/`dispatch.py` и самодостаточная база переиспользуемых скилов в `skills/`, куда каждый агент обязан превращать свой опыт решённых задач.
